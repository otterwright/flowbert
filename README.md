# Flowbert

A free, private period tracker by [Otterwright](https://otterwright.com).

This repository holds the Android downloads only. Flowbert's source code is closed; the app is free
to use, with no ads, accounts or tracking.

**Download:** get the latest APK from [Releases](https://github.com/otterwright/flowbert/releases/latest).
Each release lists the APK's SHA-256. Every Flowbert APK is signed with the same certificate:

```
SHA-256: dcade14bb453aa8020da25ba0a832bbf10cc49e382b32d10f12510fc73a53835
```

The "Source code" archives GitHub attaches to each release contain only this README.
